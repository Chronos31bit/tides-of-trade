Move the UI out of Lua and into StarterGui

Today every ScreenGui is built at runtime with Instance.new. This roadmap migrates the 16 player-facing UIs to designer-authored StarterGui templates so artists can edit layout in Studio while controllers stay focused on behavior. Each node is one combined Studio template + Lua wiring session. Click any card for a copy-ready prompt.
